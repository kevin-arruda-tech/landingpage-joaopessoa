## Sobre o Projeto

Criado pela equipe **Portal Software House**, este projeto nasceu com o objetivo de modernizar a experiência digital de quem visita ou deseja morar em João Pessoa.

A página funciona como um guia completo, rápido e visualmente atrativo, reunindo tudo o que o visitante precisa saber em um só lugar:

* **Nossa História:** Uma linha do tempo interativa contando os principais marcos da terceira capital mais antiga do Brasil.
* **O que Visitar:** Os 12 principais pontos turísticos da cidade com fotos, descrições e links diretos para traçar rotas no mapa.
* **Por que Morar Aqui:** Dados reais sobre custo de vida, áreas verdes e bem-estar social para quem pensa em se mudar para a cidade.
* **Localização e Contato:** Mapa integrado para explorar os bairros e um formulário prático para tirar dúvidas, com proteção de dados (LGPD).

## Como o Projeto foi Construído (Arquitetura)

O site foi planejado para ser leve, rápido e fácil de navegar em qualquer aparelho:

* **Funciona em Qualquer Tela:** O visual se adapta automaticamente ao tamanho da tela, oferecendo uma ótima experiência tanto no celular quanto no tablet ou computador.
* **Código Organizado:** A estrutura do conteúdo, o visual e as interações foram divididos de forma clara, facilitando futuras atualizações e melhorias na página.
* **Carregamento Rápido:** O mapa interativo e os recursos visuais foram integrados de modo a não deixar o site pesado ou lento para o usuário.
* **Publicação Online:** O projeto está conectado ao **GitHub** e publicado na plataforma **Netlify**, permitindo acesso imediato via navegador pelo link [joaopessoaturismo.netlify.app](https://joaopessoaturismo.netlify.app/).

---

## Linguagens e Ferramentas Utilizadas

* **HTML5:** Utilizado para estruturar todo o conteúdo da página de forma clara, organizada e acessível para diferentes navegadores e leitores de tela.
* **CSS3:** Responsável por todo o visual do site, aplicando as cores oficiais inspiradas no letreiro turístico de João Pessoa (azul, vermelho, amarelo e verde) e garantindo que os elementos fiquem bem alinhados em qualquer tela.
* **JavaScript:** Traz vida e interatividade para a página, fazendo funcionar a galeria de fotos em carrossel, a conferência automática dos dados digitados no formulário e o botão rápido de voltar ao topo.
* **Bootstrap 5:** Ferramenta visual utilizada para criar menus responsivos, cartões informativos e botões padronizados com agilidade e consistência.
* **GitHub:** Plataforma usada pela equipe para salvar o código, acompanhar o progresso de cada integrante e organizar as versões do projeto.
* **Netlify:** Serviço utilizado para colocar o site no ar e deixá-lo disponível na internet.

## Como Visualizar o Projeto

**Online:** acesse [https://joaopessoaturismo.netlify.app/](https://joaopessoaturismo.netlify.app/) em qualquer navegador, no celular ou no computador.

**No seu computador:**

1. Baixe ou clone este repositório pelo **GitHub**:
   ```bash
   git clone https://github.com/SEU-USUARIO/landingpage-joaopessoa.git
   ```
2. Abra a pasta `projeto-integrador`.
3. Dê dois cliques no arquivo `index.html` para abrir o site no navegador.
