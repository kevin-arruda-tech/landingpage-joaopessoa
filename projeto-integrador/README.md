# Projeto Integrador — Landing Page de João Pessoa

Nesta pasta fica o projeto integrador, ou seja, os códigos definitivos e a landing page funcional.

## Estrutura

```
projeto-integrador/
├── index.html      # página principal (landing page)
├── pages/          # páginas adicionais
├── css/
│   └── style.css   # estilos da página
├── js/
│   └── script.js   # scripts (voltar ao topo, mapa, máscara de telefone)
├── images/         # imagens do projeto
├── assets/         # fontes, ícones e outros recursos
├── docs/           # documentação
└── README.md
```

## Como executar

Abra o arquivo `index.html` no navegador.

## Tecnologias

HTML5, CSS3, JavaScript e Bootstrap 5.3 (via CDN).
